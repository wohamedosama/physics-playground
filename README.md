# 🎮 Physics Playground

### *Flutter Widget Mastery – Drag, Drop & Match with Style!*

---

## 🎯 What Makes This Special?

This isn’t just another demo – it’s a **mini interactive physics simulation** that showcases how to use Flutter’s `Draggable` and `DragTarget` widgets to build fun, engaging drag-and-drop mechanics.

---

## 🔥 **Core Features**

* 🎨 **Draggable Colored Balls** – At least 3 vibrant balls (Red, Blue, Green)
* 🏠 **Matching Drop Targets** – Drop zones that correspond to each ball
* 👆 **Interactive Drag Feedback** – Balls fade and follow your finger
* ✅ **Success State on Match** – Containers highlight when correctly matched
* ❌ **Graceful Wrong Drops** – Balls return to their original place if dropped incorrectly
* ✨ **Smooth Animations** – Subtle transitions with `AnimatedContainer`

## 🛠️ **Tech Stack & Widgets**

| Widget                | Purpose                 | Why It's Awesome                  |
| --------------------- | ----------------------- | --------------------------------- |
| `Draggable`           | Creates draggable balls | Provides smooth drag feedback     |
| `DragTarget`          | Drop zones for matching | Handles correct/incorrect matches |
| `AnimatedContainer`   | Visual feedback         | Smooth state transitions          |
| `Scaffold` + `AppBar` | UI structure            | Clean app layout                  |
| `Row` + `Column`      | Layout management       | Easy responsive positioning       |

---

## 🎮 **How to Use**

| Action               | Gesture                         | Result                         |
| -------------------- | ------------------------------- | ------------------------------ |
| **Drag Ball**        | Tap + Hold + Move               | Ball follows your finger       |
| **Drop Correctly**   | Drop ball in matching container | Container fills with color     |
| **Drop Incorrectly** | Drop in wrong container         | Ball returns to start          |
| **Drag Over Target** | Hover ball over container       | Border highlights for feedback |
